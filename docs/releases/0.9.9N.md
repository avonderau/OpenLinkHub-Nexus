# OpenLinkHub Nexus 0.9.9N

**OpenLinkHub Nexus 0.9.9N** contains the changes merged into `main` since `0.9.8N`. This is an independently maintained fork, not an official Corsair, Elgato, or upstream OpenLinkHub release.

## What's new

### Nexus editor improvements

- The touchscreen icon picker is now **paged and bounded**, so large icon libraries no longer require displaying every available icon at once.
- Widget fill **Style** has moved into the **Appearance** section, between Corner radius and Gradient, for a more consistent editing workflow.
- Fill Style is available across the supported styled widget types.
- Existing appearance settings and layouts remain supported.

### Upstream hardware and battery improvements

- Merged upstream OpenLinkHub changes, including work on **Sabre v2 Pro** support and battery/status reporting for supported wireless devices.
- Incorporated associated device and USB rule updates. Exact behavior depends on the connected hardware.
- Retained the fork's Nexus, Mirabox, experimental classic Elgato Stream Deck, plugin, and icon-pack features.

### Documentation

- Updated the README to show screenshots of the fork's actual WebUI, including the Nexus editor, Deck editor, plugin management, and icon-pack management.
- Updated supported-device and Deck plugin documentation.

## Download and install (Linux amd64)

All formats are built from the same versioned release executable, with separate SHA-256 checksum files.

| Format | Release asset |
| --- | --- |
| Debian / Ubuntu / Linux Mint | `OpenLinkHub-Nexus_0.9.9N_amd64.deb` |
| RPM | `OpenLinkHub-Nexus-0.9.9N-1.x86_64.rpm` |
| Portable Linux archive | `OpenLinkHub-Nexus-0.9.9N-linux-amd64.tar.gz` |

**Release page:** https://github.com/avonderau/OpenLinkHub-Nexus/releases/tag/0.9.9N

Verify the downloaded package using its matching `.sha256` file before installing. On Linux Mint / Ubuntu:

```bash
sha256sum -c OpenLinkHub-Nexus_0.9.9N_amd64.deb.sha256
sudo apt install ./OpenLinkHub-Nexus_0.9.9N_amd64.deb
```

Native packages require Linux x86-64 with glibc 2.38 or newer and the declared dependencies. Preserve your configuration, layouts, macros, and icon packs before upgrading. Stop separately launched test instances before starting the system service.

## Testing and limitations

- The merged branch passed its existing automated tests. The release workflow separately verifies Go and UI sources, builds the portable archive, creates the DEB/RPM files, and validates package contents before publishing.
- Native Elgato hardware support and Deck plugin compatibility remain **experimental** and require device- and plugin-specific testing.
- Plugins execute with the logged-in desktop user's permissions: install plugins only from trusted sources.
